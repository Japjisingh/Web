GlidepathCompanion for X-Plane 12

Setup

Connect X-Plane 12

  1. Use X-Plane 12.1.1 or later (the version with the built-in web API).
  2. In X-Plane open Settings → Network and allow incoming connections to the web API. It listens on port 8086.
  3. Install Node.js 22 or later. In this folder run node bridge.mjs.
  4. Open http://localhost:8787 in a browser on the same computer.
  5. Load a C172 on a runway and pick an exercise. The companion follows your flight automatically.

Using a tablet

Run node bridge.mjs --lan and open the address it prints on a tablet on the same home network. Use this only on a network you trust: neither X-Plane's web API nor this connector has a password, so anyone on the network could read your flight and trigger failures.

Study aid only

Glidepath Companion is not a certified flight training device and its scores do not count towards any licence. Figures are approximate C172S values from public sources. Always follow your aircraft's POH and your instructor.

MSFS 2024 needs a separate Windows helper built on SimConnect; it is not included. Demo mode runs entirely in your browser with no network access.
